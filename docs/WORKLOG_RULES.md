# 업무일지 자동 기입 규칙

대상 시트: `업무일지_김현호` → 탭 `업무일지` (열: 날짜, 구분, 중분류, 소분류, 사업명, 소요시간, 상세내용). 분류표는 같은 파일의 `제안업무` 탭.
입력: 제안팀 시트 `제안작업_이력` (타임스탬프, 이름, 사업명, 작업내용)의 김현호 행 + 하이웍스 메일(`daily_activity`).

## 행 생성
1. **제안 행** = 제안작업_이력의 김현호 행 1:1. 구분 `제안`, 소분류 = 작업내용, 중분류·소요시간은 아래 표. 상세내용은 메일에 구체 내용이 있을 때만.
2. **기타 행** = 내가 보낸 메일 중 제안이력에 없는 업무(투찰, 계정/행정, 자료 공유, 회의). 구분 `기타`, 소요시간 0.5 기본, 상세내용 "무엇을 누구에게" 한 줄. 받기만 한 메일은 행을 만들지 않는다.
3. **중복 방지**: 같은 날짜의 기존 행과 (소분류, 사업명) 또는 상세내용이 같으면 추가하지 않는다. 기존 행은 수정·삭제하지 않는다.

## 소분류 → 중분류 / 전형 소요시간 (2026년 6~7월 기록 기준)
| 소분류 | 중분류 | 시간 |
|---|---|---|
| 공고 업데이트 | 입찰공고 | 0.5 |
| 입찰 준비 사항 / 일정인력 중복체크 | 제안 준비 | 1 |
| 제안서 일정 | 제안서 일정 | 1 |
| 제안서 인력 | 제안서 인력 | 1 |
| 제안서 첨부 / 제안서 서류 / 정량제안서 작성 | 제안서 첨부 및 서류 | 1 |
| 정량평가 대응 | 제안서 첨부 및 서류 | 0.5 |
| 품질검수 / 블라인드 | 제안서 품질검수 | 1 |
| 제안서 통합 | 제안서 품질검수 | 0.5 |
| 직접제출 | 제안서 제출 | 1 |
| 온라인제출 | 제안서 제출 | 0.5 |
| 질의응답 / 화상발표 | 제안평가 지원 | 2 |
| 직접발표 | 제안평가 지원 | 1 |
| 개찰결과 공유 | 개찰결과 | 0.2 |
| 그림작업 요청파악 | 제안서 그림 | 0.5 |
| 실적증명서 | 제안서류 | 1 |
| 자격증사본 / 경력증명서 / 기타 제안서류 | 제안서류 | 0.5 |

소요시간은 전형값이다. 실제와 다르면 시트에서 직접 고치면 되고, 규칙을 바꾸려면 루틴 프롬프트의 표를 수정한다.

## 실행
- 루틴 "전날 업무 브리핑 + 업무일지 기입": 평일 09:51 KST, Google Sheets 커넥터 포함, 결과는 푸시·이메일 알림.
- 수동: Claude Code 세션에서 "어제 업무일지 써 줘" (work-manager 스킬).
- 첫 기입: 2026-10-14 행 2건 (제안 1, 기타 1). 7/30~10/13 공백은 제안작업_이력 기준으로 백필 가능.
