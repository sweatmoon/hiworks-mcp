# 아침 브리핑 루틴

Claude Code 예약 실행(Routine)으로 평일 09:51(KST)에 새 세션을 열어 전날 업무 브리핑을 만들고, 결과를 푸시·이메일 알림으로 보낸다. (10시 정각은 서버 혼잡으로 지연될 수 있어 9분 앞당겼다.)

## 루틴이 하는 일
1. `get_sync_status` 로 동기화 상태 확인 (오류·12시간 이상 미동기화 시 경고)
2. 전날(월요일이면 금·토·일) `daily_activity` 호출 → 발신 스레드, 받은 요청·회신 여부, 완료·등록 할 일
3. 필요한 메일은 `read_email` 로 확인 (최대 10통)
4. 브리핑 Markdown 작성 (근거 메일 번호 포함, 추측 금지)
5. `daily_brief` 로 오늘 지연·마감·새 요청 추가
6. Google 시트 도구가 연결돼 있으면 업무일지 시트에 전날 행 추가, 아니면 "기입 생략" 표기

메일 발송은 하지 않는다. MCP 도구가 없으면 curl 로 서버를 직접 호출한다 (프록시가 인증 헤더를 붙임).

## 업무일지 시트 기입을 켜려면
1. claude.ai → 설정 → 커넥터에서 Google Drive(Sheets) 연결
2. 루틴을 갱신해 커넥터를 포함시키고(`update_trigger` 또는 claude.ai 루틴 설정), 프롬프트에 시트 URL 과 열 형식을 적는다
3. 첫 실행 결과의 행을 확인하고 형식을 다듬는다

## 수동 실행
Claude Code 세션에서 "어제 업무 브리핑해 줘" 라고 하면 work-manager 스킬이 같은 절차(`daily_activity`)로 작성한다.
